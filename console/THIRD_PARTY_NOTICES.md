# Console sources and licenses

The UI components in `src/components/ui/`, `src/lib/utils.ts`, and the supporting
`src/styles/shadcn.css` were generated/copied using the official `shadcn@4.22.0`
CLI and registry, with the `base-nova` Base UI preset. They are real shadcn/ui
component sources, not a CSS naming convention. The original MIT license is
preserved in [licenses/shadcn-MIT.txt](licenses/shadcn-MIT.txt).

The CLI is not a runtime or CI dependency after generating the checked-in sources.
To add a component explicitly: `npx shadcn@4.22.0 add COMPONENT`. Review the resulting
source/dependency changes and retain the license. The supporting CSS is vendored
from that same pinned CLI package to avoid installing its unnecessary CLI-only
transitive dependencies in the build.

React, Base UI, lucide, Tailwind, Geist fonts, and the other packages retain their
own licenses. Exact versions and integrity hashes are recorded in package-lock.json.
The API SDK/client/types are generated by @hey-api/openapi-ts 0.99.0 solely from
`../api/openapi.json`; edit the specification, never the generated files.

TypeScript is pinned to 5.9.3 because the generator currently consumes its compiler
API. js-yaml is overridden to the compatible 4.3.2 security patch. No forced major
upgrade or suppression is used; the final dependency audit is clean.
